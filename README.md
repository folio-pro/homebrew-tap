# folio-pro Homebrew Tap

Homebrew tap for folio-pro apps.

## Usage

```sh
brew install folio-pro/tap/kdashboard
```

Upgrade with:

```sh
brew upgrade --cask kdashboard
```

The cask in `Casks/kdashboard.rb` is updated automatically by the [kdashboard release workflow](https://github.com/folio-pro/kdashboard/blob/main/.github/workflows/homebrew.yml) whenever a new release is published.
